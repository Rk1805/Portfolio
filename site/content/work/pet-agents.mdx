## The problem

Desktop pets are charming and useless. Assistants are useful and charmless — and most send what you type to a server. I wanted one thing that was both: a character you like having on screen, and an assistant that runs on your own machine.

## The insight

If the pet is the interface, the assistant stops feeling like a tool. And if the model runs on-device, it needs no API keys and no account — you build the app and it works.

## The build

- A native macOS app in Swift. Pets walk along the bottom of the screen and on top of windows, can be picked up and dragged, and perform signature moves.
- Free-form requests are understood by Apple Intelligence on the Mac itself. Built-in commands work even with it switched off.
- Missions it can carry out: open apps, play a song on Spotify, set reminders and calendar entries, type into other apps, open a WhatsApp chat by contact name, toggle dark mode. Push-to-talk voice input, plus built-in Hinglish commands.
- 27 characters across two packs. Every animation frame is drawn from scratch by a skeleton rig — shoulders, elbows, hips, knees — with inverse kinematics for things like bringing a hand to the mouth. Frames are 192×192 pixel art at 10 fps, generated by a Python pipeline.
- Builds with Apple's free Command Line Tools only; no Xcode, Homebrew, Node or API keys.

## The result

A working app, built and tested on macOS 26 on Apple Silicon. A solo passion project, not released yet — so no usage claims are made.
